# Bay FM music credits

| Recording | Artist | Local file | Release and license |
| --- | --- | --- | --- |
| Pure Raceway | MintoDog | `pure-raceway.ogg` | [Artist release](https://opengameart.org/content/pure-raceway) · [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| Sky Blue Street | MintoDog | `sky-blue-street.ogg` | [Artist release](https://opengameart.org/node/170985) · [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| Afterhours Run | Velocity Syndicate | `bay-fm.ogg` | Original instrumental composed and synthesized for this project |

MintoDog published both compositions and their downloadable recordings on OpenGameArt under CC0 1.0. This game uses the standard 160 BPM release of *Pure Raceway* and the standard 165 BPM release of *Sky Blue Street*. Each recording was transcoded to stereo Ogg Vorbis for local playback. [Pure Raceway source audio](https://opengameart.org/sites/default/files/pure_raceway_bpm160_0.ogg) · [Sky Blue Street source audio](https://opengameart.org/sites/default/files/sky_blue_street_bpm165_0.ogg)
